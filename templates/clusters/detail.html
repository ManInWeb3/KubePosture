Imports

{% help "Imports" %}

Last complete inventory is the start time of the most recent inventory cycle that was fully processed — the anchor every "currently deployed" decision on this cluster is made against. Last import is the most recent import the in-cluster CronJob started, whatever its outcome: one row per report kind it uploaded, with the state each reached.

An import is uploading while the importer is still sending bundles, processing once committed and being worked through, and complete when every kind has been reaped. Discarded imports were never applied (the importer never committed, or the inventory payload failed); failed means some payloads of an otherwise complete import could not be processed — the error is shown on the kind.

Namespaces

{% help "Namespaces" %}

Each row is a namespace discovered by the import CronJob.

Publicly Exposed is auto-detected from K8s state — true if any workload in the namespace is backed by an external LoadBalancer Service or a non-internal Ingress. In SSVC terms this is the open exposure state (internet-reachable). When the box is unchecked the namespace is treated as controlled: still reachable from anywhere else on the cluster network, just not from the public internet — not the same as isolated. A future revision will add a small state for namespaces with deny-all NetworkPolicy coverage and no listening ports; until then, every non-public namespace is controlled.

Sensitive Data is always manual — admin declares which namespaces process PII / financial / regulated data. A Critical CVE in a sensitive namespace is promoted to Out-of-Cycle regardless of environment.

PSS shows the pod-security.kubernetes.io/enforce label (restricted / baseline / privileged). Missing label defaults to privileged semantically.

Namespaces marked deleted were not present in the most recent complete cluster snapshot; their active findings were auto-resolved.
