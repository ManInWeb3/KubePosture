Every software component currently running across the fleet, sourced from Trivy SbomReports. Each row is one unique package URL (purl); two versions of the same library appear as two rows.

How data: Trivy Operator emits one SbomReport per workload-container; KubePosture ingests it per Image (deduplicated cross-cluster). A component is "active" iff its image is currently deployed somewhere — driven by the existing image-deployment tracking, not a separate flag.

How to use: Search by name to find a package, or paste a known-bad purl/name from a security advisory to see which workloads have it deployed. Click a row for affected images and workloads. Toggle Include undeployed to also search historical inventory.
