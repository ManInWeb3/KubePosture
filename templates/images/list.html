Container images observed across the fleet, ranked by blast-radius Impact. One row per Image (content-addressed by digest, deduplicated across clusters).

Impact = workloads currently using this image × Σ (weight × CVE count per band), with weights immediate=1000, out-of-band=100, scheduled=10, defer=1. Powers of 10 mean a single Immediate CVE on a widely-deployed image always outranks any pile of lower-band findings.

Quick wins: sort by Impact / CVE to find high-leverage images — many workloads, few CVEs. One patch unblocks many findings.

How to use: click a row to see which workloads run the image, what other CVEs exist on it, and the SBOM package count — the answer to "if I patch this image, what do I unblock?". Toggle Include undeployed to also list images observed only in past inventory cycles.
