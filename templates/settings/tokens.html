Bearer tokens for the ingest API. The kubeposture-import CronJob on each target cluster sends Authorization: Bearer <token> when posting Trivy and Kyverno reports to /api/v1/ingest/.

How to add a cluster: create a token here, copy the value (it is shown once), paste it into the cluster's Helm values.yaml under token.value (or reference a Kubernetes secret), then run helm install kubeposture-import. The cluster auto-registers on first ingest; one token can write into any cluster.

Rotate: click Regenerate — a new secret is minted and the old one stops working immediately. Delete removes the token entirely.

Name: alphanumeric, dashes, and underscores only. Typically the cluster name.
